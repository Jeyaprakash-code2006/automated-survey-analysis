# Automated Survey Analysis

## Project Description

Automated Survey Analysis is a data science project that analyzes survey responses automatically.

The system performs data cleaning, sentiment analysis, keyword extraction, NPS calculation, CSAT calculation, and generates useful insights.

## Features

- Upload survey data
- Clean survey data
- Calculate NPS
- Calculate CSAT
- Perform sentiment analysis
- Extract important keywords
- Generate automatic insights
- Display charts and visualizations
- Interactive Streamlit dashboard

## Technologies Used

- Python
- Pandas
- Streamlit
- Plotly
- Natural Language Processing
- Sentiment Analysis

## Project Files

- app.py - Main Streamlit application
- analysis.py - Data loading and analysis
- sentiment.py - Sentiment analysis
- keywords.py - Keyword extraction
- insights.py - Insight generation
- requirements.txt - Required Python packages
